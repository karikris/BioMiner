The targeting queue reuses immutable review-request bindings and ranks each
eligible reference using outlier score, competitor similarity, prototype
influence, route mismatch, provider concentration, repeated error involvement,
low subject-area ratio and duplicate ambiguity. Multiple flagged contexts
collapse into one reference row without losing any reason or policy fingerprint.

Review decisions remain append-only and source-bound. Reviewers can verify,
exclude, abstain as uncertain, correct life stage, visual domain and view, note
an alternative species, or request a second review. Multi-round tests preserve
the first decision and targeting binding while a later independent decision is
resolved through the existing conflict and second-review workflow.

The adaptive revision permits only provisional GBIF support. Eligible verified
references become human-verified support; rejected references are excluded;
unresolved targeted references are quarantined; and unflagged provisional
references retain their disposition. Every old row maps to a new row under an
exact one-step bank version increment. Downstream artifacts are invalidated only
when their declared reference dependencies intersect a materially changed row.

The remediation report distinguishes measured dispositions from future work.
A prototype invalidation is reported as “rebuild required, not measured,” and
expected impacted-record totals are present only when supplied by fingerprinted
impact evidence. Missing estimates remain unavailable rather than zero.

These are fixture-tested workflow and provenance contracts. No live reference
review, observed prototype change, production rerun, accuracy gain, reviewer
throughput, cost reduction or time-saving benefit is claimed.
